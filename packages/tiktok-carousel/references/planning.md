# 图文策划指南

## 选择叙事结构

| 结构 | 适合情况 | 建议五页推进 |
|---|---|---|
| 痛点解决 | 使用前的问题容易看见 | 具体痛点 → 使用场景 → 解决方式 → 关键细节 → 总结与行动 |
| 生活种草 | 商品在生活中有视觉吸引力 | 吸引人的场景 → 使用过程 → 核心价值 → 搭配或细节 → 行动 |
| 购买决策 | 用户需要了解尺寸、适用性或差异 | 谁适合 → 核心特点 → 尺寸或使用条件 → 常见疑问 → 选择建议 |

页数变化时按信息量合并或拆分，不为凑页数重复卖点。不强制最后一页做促销海报，延续整组生活场景也可以。

## 封面与逐页表达

封面让目标人群一眼识别场景、需求或结果。可以用具体提问、明确用途或视觉反差；不依赖夸张承诺。后续每页回答一个问题，并给下一页提供阅读理由，不机械追加“继续滑”。

图中文字短而具体，以手机阅读为准。英文标题可先尝试 4–9 个词，非硬性字数要求。优先一个标题，必要时加一句简短说明。避免把商品详情页塞进图片。将正文文字与生成指令分开保存，便于换语言。

采用自然的商品介绍口吻，不伪装亲身经历。未经用户提供依据，不写“我用了三个月”“大家都在抢”“最后一天”、虚构折扣或五星评论。对比图只呈现有依据、合理可展示的变化，不制造效果证明。

## 商品与视觉一致性

记录参考图编号、SKU/颜色、外形、Logo、结构、可见材质、随附配件和禁止变化项。看不清的部分记为未知。多张图冲突时先确定本次商品款式，不把不同款式混成一个商品。

每页生成提示词均包含原商品身份约束；已生成封面只能补充风格，不能取代原商品参考。实拍感通过光线、取景和真实使用动作表达，不用虚构顾客证言制造真实感。尺寸未知时避免借手掌等画面暗示精确大小。

推荐留出四周呼吸空间，关键文字远离边缘；这是布局建议，不宣称固定像素为 TikTok 官方安全区。真正发布或用户询问限制时再核查目标市场、内容形式和当前平台要求。

## 每页提示词构成

提示词要独立可执行，至少写清：

- 目标市场、画幅、页面角色。
- 使用哪些商品参考及不可改变的特征。
- 场景、主体动作、构图、镜头距离、光线和整组风格。
- 精确图中文字（保留目标语言）与排版；或明确无字底图及文字预留区。
- 禁止添加的功能、配件、虚构证明和无关文字。

提示词可用模型适合的语言，图中文字不得被自动翻译。文案存在未确认事实时，先替换为已知事实或标记阻塞；不要将“待确认”字样渲染进成品。

## 示例：收纳盒的生活种草角度

以下仅为结构示意，不是商品事实。假设目标为美国租房人群，只有外观图片，没有尺寸、承重与材质证明：

1. 封面：咖啡角整理后的生活场景，标题 “A little order for your coffee corner”。
2. 场景：展示咖啡小物的分类需求，不虚构容量。
3. 使用：展示可由实际外观支持的拿取动作。
4. 细节：放大已知结构；未知尺寸不展示标尺与数字。
5. 结尾：总结适用场景，邀请查看商品详情。

输出时必须替换为本次商品的真实信息，不能直接套用示例推断收纳、耐热或食品接触功能。
