# 方案开发：从用户动机到商品答案

每次策划先读本文件，再用 planning.md 展开页序。先决定值得讲什么，再决定镜头与排版。默认输出3个经过筛选的方向，不是先填满3张分镜表。

## 从案例中提取什么

以下归纳来自用户提供的图文案例及解析：牙膏、情侣互动书、秋日相机封面有截图；弹力袜与车载香薰只有解析文字。案例数据仅是历史截图或口述，不证明销量、因果关系或当前趋势。学内容机制，不继承案例的效果、时效、价格、用户证言或未经证实的功效。

| 案例 | 首图建立的用户动机 | 后续如何承接 | 可迁移的方法 |
|---|---|---|---|
| 牙膏 | 看得见的牙色困扰，加“以为改变不了”的心理阻碍 | 案例展示变化、近景反应，最后解释商品 | 问题足够具体；后页兑现首图提出的问题。只有本商品有适当依据时才能采用效果前后对比 |
| 弹力袜（文字解析） | 用户认出与自己有关的身体困扰 | 案例以变化引起解决方案好奇，再展示商品 | 从用户问题进入品类，不能照搬肿胀、循环等医学推断或改善承诺 |
| 秋日车载香薰（文字解析） | 车内南瓜与枫叶把想象中的气味变成可见体验 | 从想要这种气味，转向香薰这一实现方式 | 用与真实卖点有关的感官联想引发欲望；不把南瓜当通用流量密码 |
| 秋日相机 | 一组想收藏、想拍出来的照片，加“如何拍出这种氛围”的承诺 | 解析描述从想要的照片到拍摄工具；现有截图只验证封面 | 成果示范或有用内容先行。若承诺教程，后页必须提供方法，不能只露商品 |
| 情侣互动书 | 雨夜情侣与“想象给男友填满这个”让读者代入自己的关系 | 展示真实内页问题，读者在脑中填写自己的答案 | 情绪必须指向具体使用行为；产品内容本身能延续参与感。同一机位、版式也可以有效 |

共性是“首图先让目标用户产生一个与商品有关的念头，后页把这个念头一步步接住”。念头可以是“这就是我的问题”“我想要这种体验”“我想为某人做这件事”或“我想学会做成这样”。不是所有案例都靠笑话、戏剧反转或猜商品。

案例分析账号的口播要求不等于带货素材要求：短金句、讨论类目、避免私信引流属于解析稿；不能因此删掉用户已要求的商品 CTA。音乐能支持情绪，可建议音乐氛围，不捏造已试听曲目或热门音频；语言按目标受众选择，西语测试是选项，不因一个案例自动新增版本。

## 先建立动机链

从已知商品事实出发，为候选角度内部写清这条链：

**目标用户的具体问题/愿望 → 首图里看得见的线索 + 心里会说的话 → 下一页值得看的答案 → 商品的真实特点如何承接 → 购买理由。**

- 人群身份不是洞察。“妈妈很忙”只说明角色；要找到与商品用途相关、本人一看就能认出的处境、误解或愿望。
- 卖点不是开场。先把已知特点翻译成用户想完成的事，再决定能否用画面呈现；不要把“预切”等参数直接当成对所有人有效的 Hook。
- 趣味必须服务动机。搞笑可用，不强制每套讲笑话；买多了、找不到钥匙等趣事本身不能解释为什么需要膝盖 Tape。
- 不从体型、年龄或身份推断疾病、疼痛或疗效。证据不足时改变创意机制，不把所有商品降格为无具体关联的“给自己一点支持”。

## 内部发散与淘汰

先考虑比交付数多的角度（通常5–6个简短 Hook 足够），检查商品适配后只展开最好的3个。用户已有方向时围绕其目标优化，不为了凑数推翻已选方案。机制有以下选择，不要求每次各来一套：

| 机制 | 首图的价值 | 下一页应兑现什么 |
|---|---|---|
| 具体问题/认知阻碍 | 用户认出自己的问题，或意识到原来某需求被忽略 | 更清楚的解释、相关使用展示；有事实依据时才展示变化 |
| 想要的体验/感官联想 | 让人看见或想象商品相关的体验 | 这种体验与商品特征的对应关系 |
| 关系/情绪代入 | 用户想到自己和一个具体的人、想完成的行为 | 商品如何支持该行为，展示能让人继续代入的内容 |
| 成果/方法/收藏价值 | 先给一个想实现的目标或可保存的实用内容 | 实际步骤、细节或选择依据，商品作为工具进入 |
| 观察/误解/发现 | 一个与品类相关、值得解释的现象 | 真正的答案；显而易见的品类不硬设“猜卖什么” |

用下面的问题淘汰候选，记录一句判断依据，不用伪精确分数预测爆款：

1. **自我代入**：目标用户看到首图，具体会想到自己的什么？“好笑”“很真实”“妈妈会共情”不算答案。
2. **商品关联**：首图的问题或愿望与该品类是什么关系？替换成无关品类后，故事与收尾几乎不改也成立，说明关联弱，需改写或淘汰。不同品牌可共享同一品类动机，这不算失败。
3. **继续滑的理由**：首图留下的是哪一个有价值的问题或愿望？第二页是否已经给出部分回报？不靠隐瞒背景、反复重复忙碌或“下次出门前”拖到产品页。
4. **承接可信**：产品出现时，能否解释前面的具体需求？如果只能加一句“给自己一点支持”，或必须编造疗效、时效、评价才能连接，淘汰该角度。
5. **内容价值**：即使暂时不买，这条是否值得看完、保存或转给某个人？分别说清可能的动机，不声称一定带来互动。
6. **方案差异**：三套是否在问题/愿望、心理阻碍或内容回报上不同？超市、球场、公园三种背景不等于三个创意。

商品关联和事实依据不通过，不能靠好看的分镜、笑话或 CTA 补救。先修角度，再投入完整方案和图片生成。

## 首图与后页的承诺

首图给“可读的画面 + 用户内心话”，先成立为一条用户愿意看的内容。文字可以补心理，画面负责可见线索，不要求无字时也表达所有抽象情绪。痛点要具体，不故意夸大或丑化身体。感官隐喻可以有想象力，不必把每一套都限制为同一位主角的生活连续剧；产品实物仍须准确，表达方式遵从用户选择。

尽早回报观众：第二页通常应解释、展示细节、给方法或让情绪更具体，不只是再补一张“她很忙”。产品可以晚介绍，但需求必须早建立；品类很明显时，悬念应是怎么做、为什么、里面有什么，而不是“到底卖什么”。不强制所有产品到最后一页才出现。

每次滑动都要新增有用信息或加深代入。书内页、材料细节、实际示例可以沿用版式与机位；变化是服务阅读的手段，不是质量本身。自然反应来自眼前的信息或情境，不统一写品牌式夸赞，也不机械套 “LIKE WHATTT”。

结尾兑现开头的内容承诺，并让商品成为合理下一步：问题型回答需求，教程型完成方法，关系型落到可做的行为。幽默故事可回扣笑点；不是所有方案都要一张“笑着走出去”的收尾。CTA 按 planning.md 执行。

## STUQ：用于纠偏，不是固定脚本

目前包装支持黑色预切肌贴与日常支撑定位，使用图片支持对应膝盖贴法。不能从这些资料推出止痛、恢复活动或消肿的前后变化。

- 弱角度：“只买牛奶却买满一车 → 忙了一天 → 下次贴 Tape”。主要悬念是购物超计划，Tape 没有回答它。
- 更相关的方向：从“没有去健身房，却忽略了自己每天实际在做的活动”进入日常支撑场景。先验证首图是否具体指向活动与身体使用，而不只展示家务；后页用动作或使用细节解释关联，不用疼痛到轻松的疗效转折。
- 弱角度：“找钥匙很麻烦 → 所以买预切 Tape”。预切不能解决找钥匙；若要讲预切，必须面向已有用贴需求的人，围绕实际备贴环节及有依据的特点展开。
- 39岁、plus-size、妈妈和粉色字均是项目选择；能保留人物，但不能因此把每个方案缩成妈妈忙碌的段子。

## 对用户怎样展示

每套先用一小段交代“让谁产生什么念头、为什么与商品有关”，然后直接给首图画面及原文案、逐页承接和末页 CTA。内部筛选过程不全倒给用户，不靠“强共情、爆款潜力、转化更好”等空话推荐；推荐理由指出画面可读性、动机匹配和现有素材能否支撑。用户需要详细分镜时再增加镜头与排版信息。
