# 生成与验收

## 逐页生成原则

每页独立提示词、独立任务、`--nums 1`。只传当前页需要的参考图片；参考过多会稀释人物和构图约束。

参考图按角色排列并在提示词中明确：

1. 原笔记对应页：只参考页面作用、构图关系、信息密度、色彩和文字层级。
2. 用户素材：承担人物、地点、物件或主题身份，明确不可改变的特征。
3. 已通过的生成页：只有确需保持整组人物或视觉规则时才加入，不能取代原用户素材。

接口本身只接收 `inputReferences` 数组，不理解角色标签，因此提示词和任务档案必须记录每个路径的角色及顺序。

## 提示词结构

每页提示词完整写清：

- 目标：小红书 `3:4` 图文中的第几页及页面作用。
- 参考角色：哪些仅参考视觉，哪些必须保留身份和内容。
- 新增信息：读者从本页看懂什么。
- 画面：主体、动作、景别、视角、构图、环境、光线和色彩。
- 文字：逐字给出中文文案、主次层级、位置、留白和强调方式。
- 连续性：人物、地点、色彩和整组规则。
- 禁止项：原作者身份、原文案、水印、额外文字、虚构事实和不相关物件。

不要只写“参考原图生成同款”。对原参考页使用类似约束：

```text
参考图1仅用于理解构图、文字层级、信息密度和色彩关系。
不得复制其中的人物、品牌、原文案、水印、昵称、Logo或独特插画。
参考图2和参考图3是本次内容素材，保留其中人物身份、地点特征和真实物件。
```

## 命令示例

```bash
python3 scripts/lingtu_content_task.py \
  --kind image \
  --aspect-ratio 3:4 \
  --nums 1 \
  --prompt-file /absolute/path/to/job/prompts/01.txt \
  --reference-image /absolute/path/to/job/reference/01.jpg \
  --reference-image /absolute/path/to/user/material.jpg \
  --output-dir /absolute/path/to/job/drafts/01
```

创建成功后保留脚本输出的 `scheduleId`。需要继续轮询时使用脚本提供的 poll 参数，不为同一页静默重复提交任务。

## 自动验收

逐页查看原尺寸图片并检查：

- 指定文字是否逐字正确，有无漏字、错字、乱码或多余文字。
- 是否新增昵称、水印、Logo、按钮或无关装饰文字。
- 人物身份、地点和真实物件是否符合用户素材。
- 页面是否兑现方案中的内容作用。
- 主体和文字在手机缩略图下是否仍可识别。
- 是否复制了参考页可识别的人物、文案或独特表达。

文字或关键身份错误时，保留失败稿并修改提示词重试当前页。每页最多自动重试两次；超过后报告具体错误与已有候选，不继续消耗额度。轻微审美偏好不触发未经用户要求的无限重做。

整组检查页序推进、色彩与文字层级一致性、人物连续性及封面承诺的最终兑现。只有全部必需页面成功才标记整套完成。
