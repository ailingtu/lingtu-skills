# 拆解与策划规范

## 复刻边界

默认复刻“内容结构 + 视觉语法”，不是复制作品。可以借鉴：

- 封面如何承诺内容价值。
- 页序如何制造问题、展开和兑现。
- 构图类别、信息密度、配色关系和文字层级。
- 拼贴、近景、清单、截图感等表达机制。

必须重新创作：

- 标题和逐页文案。
- 人物、地点、品牌、物件和具体情境。
- 独特插画、图标组合、装饰和原创观点表达。

不得保留原作者人脸、昵称、水印、Logo或可识别身份。用户证明参考作品属于自己或已获授权时，可以按其授权范围提高视觉相似度，但仍不虚构事实。

## 素材描述

`assets-manifest.json` 是技术清单；视觉理解写入 `assets-analysis.json`。推荐结构：

```json
{
  "schemaVersion": 1,
  "groups": [
    {
      "name": "咖啡店环境",
      "paths": ["/absolute/path/IMG_001.jpg"],
      "summary": "午后自然光下的靠窗座位，桌面较干净",
      "types": ["地点", "环境"],
      "subjects": ["木桌", "落地窗"],
      "usableFor": ["封面", "环境介绍"],
      "visualStyle": {"lighting": "自然光", "shot": "广角中景"},
      "textSpace": "左上方",
      "quality": "direct",
      "constraints": ["保留店内窗景", "不添加不可见的店名"]
    }
  ],
  "gaps": ["缺少人物实际体验的近景"]
}
```

描述必须服务选图和生成，不写空泛审美散文。无法确认的人物关系、地点名称、服务体验或时间不能从画面猜测成事实。

## 内容结构

先写整组的一句话承诺，再设计页面。常见结构只是候选，不是硬模板：

```text
封面承诺 → 具体场景 → 关键细节 → 个人观点/方法 → 回报与行动
```

每页只承担一个主要作用，并至少新增一个信息或情绪推进。封面本身能看懂种草对象或内容价值；悬念可以保留答案，不能把主题也藏起来。

## 页面映射表

方案至少包含：

| 页码 | 页面目的 | 参考机制 | 用户素材 | AI 补充 | 精确文字 | 事实依据 |
|---|---|---|---|---|---|---|

用户素材优先。AI 补充用于缺少的环境、动作或过渡画面，并在任务档案标记为创作场景。不得生成虚假的打卡经历、服务体验、客户评价、排名、价格或数据证明。

## 发布文案

最终提供一个推荐标题、两个备选标题、正文、相关标签和可选评论区引导。语气适合小红书阅读，但不冒充用户真实体验。非商品种草默认使用收藏、分享、尝试、了解、关注或讨论型 CTA，不使用下单、购买、小黄车等电商表达。
