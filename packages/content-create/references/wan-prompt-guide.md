# Wan 3.0 提示词指南

依据用户提供的《Wan 3.0 提示词指南》PDF（4 页）整理。本文提炼提示词写法；接口字段、素材限制、分辨率和时长以 `api.md` 与脚本校验为准。仅在实际选择 `wan3.0-video` 时读取，不要求八字段格式。

## 先确定模型与素材用途

未明确指定模型时，先运行 `python3 scripts/lingtu_content_task.py --kind video --show-default-model` 查看实际默认值，再选择提示词规则。该命令不生成内容、不需要认证。生成时仍可省略 `--model` 以沿用偏好。

区分每份素材用于商品外观、人物、场景、动作、运镜还是音色。直接使用用户提供的素材，不额外生成参考图，也不要求参考图三件套。

## 按输入选择写法

- **文生视频**（PDF 第1页）：先描述主体、场景和具体运动；需要精确控制时再补充外观、动作幅度与速度、光线、景别、运镜、风格和声音。无需为简单需求堆满所有维度。
- **以确定画面为起点**（第2页图生/首尾帧公式）：当图像已确定主体、场景与风格时，重点写后续运动和运镜，避免重新描述出与图片冲突的画面。普通商品参考图并不自动等于接口的首帧控制。
- **多素材参考**（第2–3页）：明确参考对象、动作和所需台词。分别说明从图片保留什么、从视频参考什么、从音频参考什么，不笼统要求“照着素材做”。
- **多镜头叙事**（第3页）：先概述主题，再按镜头编号、时间范围和分镜内容描述。时间安排应与本次实际时长一致，人物、商品和场景需保持连贯；无需强制所有短视频只有一个镜头。

## 素材指代

按提交顺序标明素材，例如中文提示词用 `@图片1`、`@图片2`、`@视频1`、`@音频1`；非中文提示词使用对应英文指代，如 `image 1`、`video 1`、`audio 1`，按需加 `@`。同一提示词中的命名保持一致。

图片编号对应传入图片的顺序，视频和音频指代也要与各自实际提交素材逐一对应。不要引用未提交的编号，不要把素材文件 ID 当成提示词编号。指南给出这些指代写法；实际服务对指代的解析效果仍需通过输出验证，不视为脚本已进行结构化绑定。

明确参考范围，例如：

- 保持 `@图片1` 中商品的外形、颜色和细节。
- 参考 `@视频1` 的缓慢推进运镜，不引入其中的其他商品。
- 人物音色参考 `@音频1`，台词使用本次提供的新文案。

## 配音、台词与声音

声音可分别描述人声、音效和 BGM（第2页）。有台词时写清说话角色和原文，按需补充情绪、语调、语速、音色、语言或口音。台词长度应适配视频时长，多人说话时明确各自的台词归属。

`--reference-audio` / `--reference-dubbing` 上传的是参考音频。指南说明可以参考音色并说新台词，不能默认它表示原音频原样配入、逐字复读或最终音轨无损替换。用户要求复用原配音时先区分音色参考与原音轨保留需求，不承诺提示词参考能实现精确音轨保留。

需要口型配合时描述自然口型、表情与台词情绪协调；这是生成要求，不保证每次精确实现。

## 需要明确写出的控制

指南第4页说明，未规定的台词、音乐和镜头可能由模型自行发挥。按用户需求写出控制，不把下列限制无条件加到所有任务：

- 不要人物说话：写“全片无台词”；需要无旁白时也明确说明。
- 不要配乐：写“无背景音乐”。不要把“无台词”当作“静音”。
- 全片静音：同时要求无人声、无音效、无背景音乐。
- 单镜头：写“生成单镜头，一镜到底”；需要固定机位时另写“固定镜头”。
- 多镜头：写清镜头编号与时间范围。
- 不要字幕：明确“无字幕、无屏幕文字”，不等同于无台词。

## 电商示例

以下是写法示例，商品、台词、时长和声音要求应替换为用户实际需求；不要额外生成示例中没有的素材。

**商品图片参考，无台词、无 BGM：**

```text
保持 @图片1 中保温杯的外形、颜色、杯盖结构与标志不变。真实家居厨房，一只手拿起杯子，缓慢旋开杯盖，展示杯口细节，再放回桌面。15秒单镜头，一镜到底，镜头缓慢推进，自然晨光。全片无台词、无旁白、无背景音乐，只保留拿杯与旋盖的自然声音。无字幕、无屏幕文字。
```

**商品图片与音色参考，重新生成台词：**

```text
以 @图片1 中的收纳盒为商品外观参考。一位居家使用者把桌面上的文具放进收纳盒，展示整理前后的变化。15秒，自然手机拍摄风格，动作清晰。人物音色参考 @音频1，以轻松自然的中文、适中语速说：“桌面收拾好了，找东西也方便多了。”口型和表情与台词配合。保留轻微的物品摆放声，无背景音乐，无字幕、无屏幕文字。
```

## 接口边界与提交前检查

- 当前脚本通过 `inputReference` / `inputReferences`、`videoFileIds`、`audioFileIds` 传素材。提示词里的素材顺序和用途必须与提交内容一致。
- 指南中的首尾帧、视频编辑和延长是能力与写法说明，不能据此虚构当前接口未确认的参数或宣称已接入专门工作流。参考源视频结构改编生成由本 Skill 的 `viral-remake-workflow.md` 处理；爆款复刻（分段重绘与合成）使用 `lingtu-video-remake`。
- 指南示例里的“8K”等文字不是输出规格。默认视频输出仍为 480p；不把示例的分辨率或时长直接套入任务，提示词也不写与实际参数冲突的规格。
- 指定固定时长时，分镜时间范围不超出该时长；使用智能时长 `-1` 时避免同时要求一个冲突的固定总时长。
- 生成前检查商品一致性、台词归属、声音约束、素材指代和参数是否冲突。效果不符时说明具体问题，不因提示词规则自动增加生成次数。
